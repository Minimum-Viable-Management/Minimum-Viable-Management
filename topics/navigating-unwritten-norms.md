# 🧭 Navigating Unwritten Norms

Unwritten norms decide how work really gets done, so leaders need to surface them, translate them for newcomers, and test them safely.

## 🔑 Key Points

- Written values usually omit the most important behaviours, so look for what is missing or reversed.
- Every norm has a trade-off; speed can look like recklessness and deliberation can look like slowness.
- Start by following the stated norm, then run a small experiment when it blocks progress.
- Use smaller or private spaces to surface uncomfortable truths, then bring the learning back to the wider group.
- Leaders should take the first risk to challenge a norm so others have permission to speak and act.

## 🛠️ Put It Into Practice

1. Ask new team members to list the norms they expected versus the ones they discovered in their first month.
2. Pick one norm to test, announce a time-box, and commit to reversing the change if it harms delivery.
3. When a norm blocks delivery, describe the trade-off out loud and ask which value the team wants to optimise for.
4. Maintain a short "how we work here" note that captures unwritten norms and update it quarterly.
