# 🏛️ Working With Institutional Inertia

Institutions are built to preserve their identity, so leaders need to understand the organisation as an entity before they try to change it.

## 🔑 Key Points

- Institutions optimise for stability, so change feels uphill and needs explicit expectations about effort and time.
- Treat the organisation as a real entity with history, preferences, and behaviours rather than a single leader.
- Long-lived organisations carry scars that show up as process, so trace which past failures created today's guardrails.
- Newcomers add valuable pressure to question inherited constraints, but the learning journey cannot be skipped.
- Different parts of the institution move at different speeds, so the core mission sets the cadence you must respect.

## 🛠️ Put It Into Practice

1. Interview three long-tenured colleagues about which decisions the institution will always protect and why.
2. Map three recurring processes to the original incident or value they protect, then document the story in your team notes.
3. Ask new hires to list their first "why is this here" reactions, then revisit the list after six weeks.
4. Before proposing change, state which institutional value you intend to preserve.
